# Audit anti-slop 001: UI Termos (2026-10-14)

Cakupan: renderer `src/renderer/src` di branch `termos-native` (commit 5d7bace).
Arah desain: `DESIGN.md` (utilitarian, grafit + satu aksen amber, daftar padat, tanpa emoji, font sistem).
Design Read: aplikasi desktop SSH/Proxmox untuk sysadmin, bahasa visual alat kerja, dial ENERGY 1 / RHYTHM 1 / MOTION 1.

Prioritas mengikuti tier aturan: Hard Gate = TINGGI, Purpose-Gate = SEDANG, Quality Lock = RENDAH.
Belum ada yang diubah. Pilih nomor yang mau diperbaiki; nomor yang tidak disebut tidak akan disentuh.

## TINGGI

**1. Kontras teks redup di bawah WCAG AA** (R-25)
`--text-3` (#6b7489) hanya 4.03:1 di latar utama, 3.75 di `bg-2`, 3.43 di `bg-3`, 3.01 di `bg-4`. Dipakai untuk teks kecil (alamat host, tanggal, hint form, "baru saja"). Teks putih di tombol biru utama hanya 3.16:1. Minimum 4.5:1.

**2. Banyak kontrol tidak bisa dipakai lewat keyboard** (R-32)
Tab sesi dan tombol "+" (`App.tsx:109,119,141`), kartu host dan grup (`HostsView.tsx:146,166,212`), baris file SFTP (`SftpPanel.tsx:352`), dan header node Proxmox (`ProxmoxView.tsx:505`) adalah `div` dengan `onClick`, jadi tidak terjangkau dengan Tab/Enter. Tombol aksi kartu host baru muncul saat mouse hover. Input menghapus outline (`styles.css:313`) dan hanya mengganti warna border 1px, sehingga fokus sulit terlihat.

**3. Em dash di teks UI** (R-02)
9 opsi dropdown "— tidak ada —", "— langsung —", "— default —", "— tanpa grup —", "— otomatis —" (`HostEditor.tsx`, `KeychainView.tsx`, `ProxmoxView.tsx:211`), pesan tes Proxmox "Terhubung — Proxmox VE" (`ProxmoxView.tsx:83`), dan deskripsi paket (`package.json:5`, ikut tampil di installer).

**4. Logo dibuat tanpa instruksi** (R-23, juga R-01)
Kotak "T" bergradien biru ke ungu (`styles.css:92`) di sidebar dan layar kunci dibuat tanpa diminta. Harus jadi wordmark teks "Termos" saja sampai ada logo resmi.

## SEDANG

**5. Emoji sebagai ikon dan dekorasi** (R-04)
Menu samping (🖥 🔑 ⚡ 🗄 🛡 🕘 ⚙), tombol (📁 SFTP, ⚡ Snippet, ⚡ Quick connect, 🔒 Kunci sekarang), ikon file SFTP (📁 🔗 📄), avatar keychain (🔑 👤), empty state besar (🖥️ ⚡ 🗄️ ⇄), dan tombol Proxmox (🖥 📷 🌐 ☰ ＋). DESIGN.md: label teks, tanpa emoji.

**6. Tombol Proxmox hanya simbol** (R-04)
Aksi VM/CT (▶ ⏻ ↻ ⏸ ■ 🖥 📷 ＋) dan tombol edit/duplikat/hapus host (✎ ⧉ 🗑) hanya berupa simbol; artinya cuma ada di tooltip. Untuk aksi berisiko seperti Stop paksa, ini mudah salah klik.

**7. Gradien dan cahaya bulat di layar kunci** (R-01)
Dua `radial-gradient` ungu/navy di belakang kartu login (`styles.css:702-703`). Tidak melayani hierarki apa pun.

**8. Tipografi default AI** (R-06)
UI memakai Inter, terminal JetBrains Mono / Fira Code (`styles.css:16,35`) tanpa alasan brand. Judul seksi berhuruf kapital dengan spasi lebar ("TERAKHIR DIPAKAI", `styles.css:255-256`). DESIGN.md: font sistem.

**9. Host ditampilkan sebagai grid kartu seragam** (R-14, R-05, C-3)
Semua host jadi kartu identik dengan avatar inisial berwarna. Seksi "Terakhir dipakai" menduplikasi host yang sama persis di atas daftar host (terlihat di screenshot: test-ssh muncul dua kali). DESIGN.md: daftar padat seperti tabel (nama, alamat, terakhir dipakai), diurutkan sesuai kebutuhan.

**10. Bayangan besar tanpa alasan elevasi** (R-12)
Kartu login (`styles.css:711`) dan toast (`:569`) memakai bayangan besar. Modal (`:532`) boleh tetap, karena memang melayang di atas konten.

## RENDAH

**11. Terlalu banyak warna** (R-29)
Palet avatar 8 warna (`lib.ts:4`), pil VM biru dan CT hijau toska, ditambah aksen biru dan warna status. Jauh melebihi 2-3 warna inti + 1 aksen.

**12. Aksen biru di mana-mana, dasar biru navy** (R-20, satu aksen)
Biru dipakai di tombol utama, garis tab aktif, fokus input, progress bar, seleksi SFTP, kursor terminal, dan avatar. Latar `#0f1117` bertint navy adalah gelap "dev tool" yang generik. DESIGN.md: grafit netral + amber hanya untuk aksi utama dan sesi aktif.

**13. Identitas generik** (R-20)
Kalau nama Termos diganti, tampilannya bisa milik aplikasi apa saja. Perbaikan nomor 4, 5, 8, 9, 12 adalah yang membentuk identitas (motif: daftar padat + label teks + satu amber).

**14. Tab "⌂ Vault" membingungkan** (C-1)
Tab pertama bernama "Vault" tapi isinya menu Hosts/Keychain/dll. Lebih jelas kalau tab itu menampilkan nama halaman yang sedang dibuka.
