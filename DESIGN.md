# Termos design direction

Source: chosen by the product owner on 2026-10-14 ("Utilitarian, alat kerja"). The agent only transcribed the choice; anything not listed here is still open and must be asked, not invented.

## Identity

A work tool for sysadmins. It should feel like an instrument you operate all day, not a landing page or a dashboard.

## Palette

- Base: neutral graphite dark (grey without a blue or navy tint).
- Accent: one warm amber, used only for the primary action and for the active session. Nowhere else.
- Status colors (connected, error) only where they mark a real state.

## Layout

- Dense, table-like lists (name, address, last used) instead of card grids.
- Sidebar with text labels and keyboard shortcut hints.

## Typography

- System UI font for the interface.
- Monospace only where content is literally terminal or code (terminal, addresses, fingerprints, scripts).

## Decoration

- Text labels, no emoji.

## Dials

Dial: ENERGY 1 / RHYTHM 1 / MOTION 1
(Calm tool; uniform rhythm is deliberate for scanning dense lists; hover/focus states only.)
